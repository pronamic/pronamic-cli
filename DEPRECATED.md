# Deprecated and Archived

Pronamic CLI is deprecated and archived. This repository is no longer maintained, and no new features, bug fixes, or releases are planned.

The project was useful for workflows such as reviewing commits, creating changelogs, preparing release candidates, and deploying WordPress projects. With the rise of AI-assisted development tools, these workflows can now be handled without this CLI, so the project no longer offers enough added value to justify continued development.

Existing code and documentation are retained as a historical reference only. They should not be treated as an actively supported or recommended solution. Please use current tools and workflows, including AI-assisted tools where appropriate, for new projects.

This deprecation is intentional and corresponds with the decision to close the repository's issues as **not planned**.
